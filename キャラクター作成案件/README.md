画像はGitHubで扱いやすいように、生成画像を幅1200px程度のJPEGに変換して保存しています。元の生成画像はCodexの生成画像フォルダにも残っています。

現時点の主な仕様：

- だるま型の赤い本体
- 天狗の鼻、羽団扇、眉、ひげ
- てんとうむしの甲羅、斑点、羽根、触角
- 空っぽのだるまの目
- 着脱式の願掛けサングラス
- 6方向設定図
- 陶器またはABS／PC-ABS樹脂での製作を検討
- Makuake向けの少量限定販売を検討
