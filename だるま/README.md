# だるま｜天狗 × 狸 × だるま キャラクター企画

日本の伝統的な天狗・狸・だるまを融合した、赤を基調とする「福を呼ぶ守り神」のキャラクター企画です。

## コンセプト

> 見た目はちょっと怖いけれど、福を呼ぶのは誰よりも得意。

可愛いだけのマスコットにはしない。長い赤鼻、細い半目、太い白眉、狸の丸い耳とふさふさの尻尾、だるま型の丸い胴体で、少し頑固で愛嬌のある存在を表現する。

- **天狗**：神秘性・知恵・守護（赤い長鼻、頭襟、葉団扇）
- **狸**：親しみ・ユーモア・暮らしの温かみ（耳、目の模様、尻尾）
- **だるま**：招福・開運・願掛け（赤い丸胴、金色の「福」）
- **主な色**：朱赤、金、茶、生成り、墨色
- **性格**：頑固でおせっかいだが、実は優しい
- **仮称**：「てんたぬだる」（正式名称は未確定）

## 制作方針

1. 原案は「やや怖い」「縁起がよい」「どこか間が抜けている」のバランスを維持する。
2. サムネイル・SNS・スタンプ用途では「鼻・目・耳・赤い丸胴・尻尾」の5要素を優先して簡略化する。
3. 伝統装飾の多い**詳細版**と、形状が伝わる**簡易版**の両方を管理する。
