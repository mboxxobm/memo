## 第2段階：統計（未着手）
- 作品ごと／三部作合計の語数、異なり語数
- 動詞を原形で集計：go / went / gone → go。get / got → get など
- 登場回数ランキング TOP 50 / TOP 100
- 動詞＋目的語、動詞＋前置詞のよくある形
- 自動詞／他動詞は「単語」ではなく例文の用法ごとに判定
- get、have、do、go などは文脈・品詞判定の誤差に注意

## 第3段階：英語教材（未着手）
- 頻出動詞を難易度順に整理
- 原形、過去形、過去分詞、日本語の意味、文型、用法解説
- 映画の場面メモとリンク／位置情報（利用可能なら時刻）
- 著作権に配慮した短い引用と、独自の例文・説明

## 第4段階：復習クイズ（未着手）
- 自動詞／他動詞の二択
- 英語動詞の原形・過去形・過去分詞
- 動詞＋前置詞の穴埋め
- セリフの場面を手がかりにした英語表現の確認
- 間違えた動詞を次の日に再出題

## 想定する解析データ形式（原文本文の公開は禁止）
作品別の内部データを、次の形で処理する。

- `movie_id`：1 / 2 / 3
- `source_url` / `source_type`：出典、字幕か書き起こしか
- `sequence` / `start_time`：順番、時刻（あれば）
- `speaker`：話者（判別できるときのみ）
- `text_en` / `text_ja`：利用権限のある原文（非公開で扱う）
- `lemma` / `surface` / `verb_usage`：原形、登場形、文中の自他用法
- `validation_status`：音声・字幕との照合状態
